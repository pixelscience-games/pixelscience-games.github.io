PixelScience YouTube 投稿ツールのプライバシーポリシー

このツールは、YouTube チャンネル「Pixel Science（ピクセルサイエンス）」の運営者が、自分のチャンネルに動画を予約投稿し、説明文やコメントを管理し、再生の数字を読むために使う、運営者専用のツールです。ほかの人は使えません。

  • 使う情報：YouTube Data API と YouTube Analytics API を通して、運営者自身のチャンネルの動画、説明文、コメント、再生の数字だけを読み書きします。
  • 保存場所：許可の情報（トークン）と読み取った数字は、運営者のパソコンの中だけに保存します。外部のサーバーには送りません。
  • 第三者への提供：情報を売ったり、第三者に渡したりしません。
  • 許可の取り消し：Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも取り消せます。
  • Google のポリシー：YouTube API サービス利用規約と Google のプライバシーポリシー（https://policies.google.com/privacy）に従います。
